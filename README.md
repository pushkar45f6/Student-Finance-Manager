# Student Finance — React Native prototype

## Run
1. Install Node.js.
2. `npm install`
3. `npx expo start`
4. Open with Expo Go, Android emulator, or iOS simulator.

This is a UI prototype based on the agreed concept:
- Home dashboard
- Budget + safe-to-spend
- Spending alerts
- Upcoming expense calendar
- Quick expense entry
- Goals
- Insights
- Settings
- Hamburger navigation drawer
- AI assistant as a floating bottom-right button

The data is mock data for now. The next step would be splitting screens/components and connecting Supabase + a real financial data model.
